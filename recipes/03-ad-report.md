# 레시피 03. 광고 성과 리포트 (CSV 분석)

> **Claude (+ Notion)**
> 광고 성과 CSV를 붙여 넣으면 캠페인별 합계와 지표(클릭률, 클릭당 비용, 전환당 비용, ROAS), 전주 대비, 이상한 값을 정리합니다.

| 항목 | 내용 |
|---|---|
| 결과물 | 캠페인별 합계, 지표, 전주 대비 변화, 이상 징후 목록 |
| 필요한 도구 | Claude (결과를 저장하려면 Notion) |
| 난이도 | 하 (데이터 형식이 깨끗할 때) |
| 사전 준비 | 광고 플랫폼에서 내려받은 CSV, 지난주 ROAS |
| 검증 일자와 환경 | 2026-10-13, **합성 데이터**로 직접 실행 |

> ⚠️ **실제 광고 데이터가 아니라 컴퓨터로 만든 무작위 데이터 2벌**로 시험했습니다. 실제 플랫폼 내보내기 파일(Meta, 네이버, 구글 등)은 시험하지 않았습니다.
> 원래 구상한 "보고서를 이메일로 전달하고 보관"하는 단계(Gmail, Drive)는 **시험하지 않았습니다.** 이 문서는 CSV를 분석하는 부분만 다룹니다.

---

## 이런 분께 맞습니다
- 주간 광고 성과를 표로 받아서 합계와 지표를 매번 손으로 계산하는 마케터
- 숫자가 맞는지, 이상한 값이 없는지 빠르게 점검하고 싶은 분

## 이런 분께는 안 맞습니다
- 수백 행 이상의 데이터를 AI에게 직접 계산시키려는 분 (아래 "막힌 것" 참고)
- 해석과 전략 제안까지 믿고 쓰려는 분 (이번 시험은 **숫자 계산과 이상치 발견**만 채점했고 해석 품질은 채점하지 않았습니다)

---

## 진행 순서

1. 광고 플랫폼에서 CSV를 내려받습니다.
2. 아래 시작 프롬프트에 CSV를 붙여 넣고 지난주 ROAS를 함께 줍니다.
3. 결과의 **합계를 파일의 합계 행(있다면)과 대조**하고, 이상 징후를 직접 확인합니다.
4. (선택) 정리한 리포트를 Notion에 저장합니다.

---

## 시작 프롬프트 (그대로 복사해서 쓰세요)

```
아래는 지난주 광고 성과 CSV입니다.

[CSV 붙여넣기]

지난주 ROAS: [캠페인명: 값, ...]

1. 숫자에 붙은 쉼표, 원화 기호, % 를 제거해서 읽어줘.
   합계 행이 있으면 합산에서 빼고, 마지막에 내 합계와 대조해줘.
   완전히 같은 행이 중복되면 한 번만 세고, 어떤 행인지 알려줘.
2. 캠페인별로 노출, 클릭, 비용, 전환, 매출의 합계를 구하고
   클릭률, 클릭당 비용, 전환당 비용, ROAS를 계산해줘.
   각 합계의 계산 과정을 보여줘.
3. 전체 합계와 전체 지표도 구하고, 지난주 ROAS 대비 변화율을 알려줘.
4. 이상한 값을 알려줘. 예: 클릭이 노출보다 많은 행, 비용이 갑자기 늘었는데 전환이 0인 행.
   왜 이상하다고 판단했는지 근거도 같이.
5. 이유를 단정하지 말고 '가능한 원인'으로만 적어줘. 데이터에 없는 사실은 지어내지 마.
6. 마지막에 확신이 없는 숫자나 내가 둔 가정을 따로 적어줘.
```

## 실제로 돌려보고 알게 된 것

### 시험 방법 (블라인드 채점)
- 컴퓨터로 **무작위 광고 데이터**를 만들고, 정답 계산을 **파일에 숨겨 둔 채** AI가 낸 숫자를 나중에 대조했습니다.
- AI는 **코드를 실행하지 않고** 합계와 지표를 직접 계산했습니다. (코드 실행 도구 없이 채팅에 CSV를 붙여 넣는 상황을 흉내 낸 것입니다.)

| 시험 | 데이터 | 항목 수 | 결과 |
|---|---|---|---|
| 1 | 깨끗한 CSV (캠페인 3개 × 7일, 21행), 이상치 2개를 심어 둠 | 41 | **41/41 일치**, 심어 둔 이상치 2개 모두 발견 |
| 2 | 내보내기 파일 모양 (한글 헤더, 쉼표, `₩`, `%`, **중복 행 1개, 합계 행**) | 37 | **37/37 일치**, 중복 행 발견 |

- 시험 1에서 발견한 이상치: ① 클릭이 노출보다 많은 행(데이터 오류), ② 비용이 다른 날의 약 3배인데 전환과 매출이 0인 행.
- 시험 2: 중복 행은 한 번만 세고, 합계 행은 합산에서 빼고 **검산에 썼습니다.** 제 합계 5개가 파일의 합계 행과 모두 맞았습니다.
- **합계 행과의 대조가 가장 쉬운 검산법**입니다. 파일에 합계 행이 있다면 꼭 대조하세요.

### 과신하면 안 되는 이유
- **합성 데이터입니다.** 실제 플랫폼 파일에는 결측값, 이상한 날짜 형식, 같은 광고 그룹의 여러 줄, 통화 단위 혼용 같은 더 지저분한 경우가 있습니다. 시험하지 않았습니다.
- **행이 적습니다.** 21~22행이었습니다. 수백 행 이상에서는 직접 계산이 현실적이지 않고 틀릴 가능성이 커집니다.
- 이번 계산은 **각 합계의 중간 계산을 하나씩 적으면서** 했습니다. 중간 계산 없이 결과만 바로 답하게 하면 정확도가 같을지는 모릅니다.
- **한 번씩만 시험**했고, 모델이나 설정에 따라 결과가 다를 수 있습니다.
- 채점한 것은 **계산과 이상치 발견**뿐입니다. "왜 그런지"에 대한 해석이 맞는지는 채점하지 않았습니다.

### 막힌 것, 주의할 것
| 문제 | 설명 | 대처 |
|---|---|---|
| **행이 많으면 직접 계산이 비현실적** | 시험은 21~22행이었음 | 행이 많으면 AI에게 **코드나 스프레드시트로 계산**하게 하거나, 합계는 스프레드시트로 구하고 AI에게는 해석만 시키세요. |
| **중복 행과 합계 행** | 내보내기 파일에 자주 섞임. 그대로 합치면 숫자가 부풀려짐 | 프롬프트 1번처럼 **명시적으로 지시**하세요. 이번 시험에서는 지시했고 잘 처리했습니다. 지시하지 않았을 때는 시험하지 않았습니다. |
| **이상치 판단은 사람 몫** | AI가 찾은 이상한 값이 실제 문제인지는 광고 계정에서 확인해야 함 | 목록을 **확인 후보**로만 쓰세요. |
| **원인을 지어낼 위험** | 이상치의 원인을 단정하는 문장이 나올 수 있음 | 프롬프트 5번처럼 "가능한 원인"으로만 쓰게 하세요. 이번에는 해석을 채점하지 않았습니다. |
| **개인 정보와 계정 정보** | 실제 광고 데이터에는 계정 ID, 거래처 정보가 섞일 수 있음 | 필요한 열만 붙여 넣으세요. |

### 아직 검증하지 못한 것 (솔직하게 밝힙니다)
- **실제 광고 플랫폼 내보내기 파일** (Meta, 네이버, 구글 등)
- **결측값, 날짜 형식 불일치, 통화 혼용**
- **수백 행 이상의 큰 데이터**, 코드나 스프레드시트와 병행했을 때의 정확도
- **중복 행과 합계 행을 지시하지 않았을 때**의 처리
- **해석과 제안의 품질**
- **리포트를 이메일로 전달하고 Drive에 보관하는 단계** (Gmail과 Drive 연결이 필요해 시험하지 않음)
- Notion 저장은 레시피 04와 06에서 확인한 방식과 같아서 이번에는 생략했습니다.

## 마무리 체크리스트

- [ ] 합계를 파일의 합계 행과 대조했는가 (합계 행이 있을 때)
- [ ] 중복 행과 합계 행이 합산에 들어가지 않았는가
- [ ] AI가 찾은 이상한 값을 광고 계정에서 직접 확인했는가
- [ ] 이유가 단정적으로 쓰여 있지 않은가
- [ ] 필요한 열만 붙여 넣었는가 (계정 정보 제외)

> 이 레시피는 반복적인 합계와 지표 계산을 줄이는 도구입니다. 숫자를 보고 무엇을 할지는 사람이 판단합니다.
