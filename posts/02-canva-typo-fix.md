# 스레드 글 02: Canva 시안 오타, 정확한 문구를 직접 꽂기

- 상태: **미게시**
- 게시일: (  )
- 글자 수: 149자, 154자, 154자, 161자 (500자 제한 여유)

> 01번 글을 이미 올렸다면 메인 글의 정정 문단이 필요합니다.
> 01번을 아직 올리지 않았다면 정정 문단("지난 글의 ... 정정합니다")과 "지난번엔 '검수 필수'라고 썼는데"를 빼세요.

## 메인 글 (1/4)
```
AI가 만든 광고 시안에서 브랜드명이 틀렸다면, 어떻게 막으세요?

지난번엔 '검수 필수'라고 썼는데, 이번에 더 나은 방법을 찾았습니다.

그리고 지난 글의 '이미지 속 한글이 틀립니다'는 정확하지 않았어요. 이미지가 아니라 편집 가능한 텍스트였습니다. 정정합니다.
```

## 댓글 1 (2/4) 방법
```
핵심은 글자를 AI에게 다시 쓰게 하지 않는 것.

1. 잘 만든 시안을 '복사'
2. 복사본의 텍스트 요소를 정확한 문구로 직접 교체
3. 미리보기로 확인

해보니 교체한 6개 문구가 입력한 그대로 들어갔고, 브랜드명 요소는 건드리지 않아 '모닝블룸'이 그대로 유지됐습니다.
```

## 댓글 2 (3/4) 함정
```
⚠️ 새 문구가 원래보다 길면 레이아웃이 따라오지 않습니다.

상자 폭이 고정이라 줄이 바뀌면서 글자가 겹치고 잘렸어요(3곳). 상자 폭을 넓히고 위치를 맞추니 정상으로 돌아왔습니다.

그래서 교체 후 미리보기 확인은 필수입니다. 원본은 건드리지 않고 복사본에서만 작업하세요.
```

## 댓글 3 (4/4) 못 한 것
```
아직 못 한 것도 있습니다.

· 사진은 그대로라 문구와 안 맞을 수 있음 (이미지 교체는 시험 안 함)
· Canva 브랜드 템플릿 자동 채우기: 이 계정엔 템플릿이 없고 채우는 도구도 없어서 끝까지 못 해봄
· 카페(가상 브랜드) 1건만 테스트

해보신 분 있으면 어땠는지 알려주세요.
```

> "6개 문구가 입력한 그대로"는 시안 1개(복사본)에서 확인한 결과입니다.
> 스크린샷을 붙이려면 수정 전(글자 겹침)과 수정 후를 새로 만들어야 합니다. 실험 복사본의 편집은 저장하지 않고 취소했습니다.
