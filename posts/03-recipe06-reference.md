# 스레드 글 03: 레시피 6번 레퍼런스 자동 아카이빙 (단독 글)

- 상태: **미게시**
- 게시일: (  )
- 글자 수: 210자 (500자 제한 여유)

```
레퍼런스 자동 아카이빙(Claude + 브라우저 + Notion)을 해봤습니다.

✅ 공개 랜딩페이지 3곳: 읽고, 훅·구조·CTA를 분석해 Notion에 저장까지 약 2분
⚠️ 인스타그램: 프로필 헤더만 읽히고 게시물 본문과 이미지는 안 읽힘
⚠️ 페이지의 데모 화면 숫자가 실제 수치처럼 섞여 나옴

로그인이 필요한 소스는 약합니다. 내가 캡션을 붙여주는 방식이 필요해요.
```

> "약 2분"은 3개 페이지를 한 번 실행한 측정이고, 인스타그램 확인 시간이 포함돼 있습니다.
> 내장 브라우저로 한 검증입니다. 내 크롬(Claude in Chrome)은 검증하지 않았습니다.
> "캡션을 붙여주는 방식"은 아직 해보지 않은 대안이므로 "필요해요"는 제안이지 검증된 해결책이 아닙니다.
